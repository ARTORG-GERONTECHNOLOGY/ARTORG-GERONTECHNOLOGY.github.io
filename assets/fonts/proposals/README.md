# Proposal print fonts

These three unmodified Liberation Sans faces were copied from the verified local
LibreOffice 26.8.2 distribution. Liberation Sans is the Arial-compatible substitute
used for the Word template's 12pt title and 10pt body. The font software is covered
by SIL OFL 1.1; the upstream license is included. Source: liberationfonts/liberation-fonts.
PDF pagination and accented glyphs were visually verified on Windows on 2026-11-12.
